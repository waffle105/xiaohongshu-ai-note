# 小红书 AI 笔记视觉与话题参考

## 视觉方向

### A. 温暖编辑感科技极简（默认）

- 适合：AI 趋势、职业思考、能力判断、行业观点。
- 色彩：暖白 `#F6F3EE`、深墨 `#17191C`、低饱和钴蓝 `#3E63DD`，可用酸橙绿作小面积强调。
- 构图：大标题 + 单一视觉隐喻 + 明确留白；使用细网格、页码、边角标注增强“杂志页”感觉。
- 视觉隐喻：桥梁、接口、管道、控制台、拼图、分层系统、正在闭合的回路。
- 气质：温暖、轻知性、细腻、有人情味；减少纯黑霓虹和过度赛博感，让用户愿意靠近并读下去。

### B. 工具实验室

- 适合：提示词、工作流、智能体、自动化教程、效率工具。
- 色彩：冷灰或浅蓝底，蓝紫/荧光绿作信号色。
- 构图：步骤编号、模块卡、流程箭头、输入/处理/输出三段式；让页面像一张简洁的实验记录。
- 视觉隐喻：工作台、节点网络、流程管道、拆开的模块、光标与输入框。

### C. 现实感工作场景

- 适合：AI 落地、团队协作、成本、可靠性、治理、案例复盘。
- 色彩：米白、炭黑、砖红或深绿，降低“未来炫技感”。
- 构图：桌面、会议、文档、验收清单、流程墙等真实物件；画面中保留大块干净区域放标题。
- 视觉隐喻：交付台、质检章、文件夹、被标注的流程图、从草稿到成品的工作台。

## 逐页模板

### 单图观点卡

```text
上方：小标签（AI / 观点 / 2026）
中部：12–24 字主标题，形成视觉重心
下方：20–45 字副标题或场景引导，说明读者为什么要看
底部：30–60 字解释或一个可回答的问题
角落：账号/系列名与编号（可选）
背景：一个隐喻主体，不超过 2 个装饰元素；视觉不替代文字
```

### 三页对照卡

```text
1. 封面：主标题 + 场景副标题，先让读者认出自己的问题
2. 对照：聊天框里的漂亮答案 vs 现实工作里的资料、流程和验收；补充一段解释和一个微型例子
3. 收束：总结判断 + 今天能做的一步 + 一个具体提问
```

### 五页方法卡

```text
1. 封面：主标题 + 场景副标题 + 一句读者收益
2. 问题：一个常见工作瞬间 + 为什么漂亮答案仍然不够
3. 框架：资料 / 经验 / 流程 / 验收标准，每项写清解决什么问题
4. 落地：给 3–4 个动作或检查项，说明如何从一项重复工作开始
5. 收束：可引用的总结 + 收藏理由 + 具体评论问题
```

## 内容型页面比例

- 文字区域约占画面 55%–65%，视觉隐喻约占 35%–45%。
- 普通内页至少安排一个 35–70 字解释段和 2–4 条支撑点；不要让图标、箭头和留白占满页面。
- 视觉可以使用工作台、文档、批注、清单和流程痕迹增强真实感，但不要用抽象 3D 物体替代观点解释。
- 页面之间保持风格一致、信息任务不同：封面负责停留，问题页负责代入，框架页负责收藏，落地页负责行动，收束页负责讨论。

## 字体与手绘控制

- 全组优先使用思源黑体 / Noto Sans CJK SC；标题使用 SemiBold，正文使用 Regular/Medium，不要跨页面更换字体风格。
- 1080×1350 画布中，标题约 52–64 px，正文约 34–42 px，小标签约 24–28 px；标题与正文大小控制在 1.35–1.6 倍。
- 默认使用“编辑排版 + 手绘批注”混合风：手绘下划线、圈选、箭头或胶带只用于强调重点，不超过画面 15%。
- 数据、技术定义、治理和风险类内容使用纯编辑风；个人经验、轻教程和职业观察可以提高一点手绘感，但仍保持统一字体和可读正文。

## 标题句式

优先从以下句式中选一个，再替换为原文真实内容：

- “未来比的不是会不会用 AI，而是能不能稳定交付”
- “AI 真正拉开差距的地方，不在聊天框里”
- “只会问 AI，和能把事交给 AI，是两种能力”
- “为什么很多 AI Demo 很惊艳，工作结果却不稳定？”
- “把这 4 样东西接进 AI，才会得到可复用的工作流”
- “AI 进入现实世界后，真正难的是这 4 个字：可交付”

不要把句式当成事实结论；根据原文改写，避免所有笔记都使用相同的“不是 A，而是 B”。

## 话题组合

每篇选 6–10 个，保持相关性：

- 核心：`#人工智能` `#AI` `#生成式AI` `#AI工具`
- 方法：`#AI工作流` `#提示词` `#智能体` `#自动化`
- 场景：`#职场效率` `#知识管理` `#产品经理` `#创业思考`
- 认知：`#科技趋势` `#未来工作` `#认知升级` `#效率提升`

根据正文删减，不要同时堆满所有词。工具测评应加入具体工具名；如果原文没有提到具体工具，不要补写品牌名。

## 文案语气

- 用“我观察到 / 更值得关注的是 / 真正难的是 / 可以先从……开始”表达判断。
- 少用“颠覆、革命、降维打击、人人都要、必然失业”等绝对化或贩卖焦虑的词。
- 每段 1–3 句，关键句单独成段；emoji 每篇 0–3 个，只有在能帮助节奏时使用。
- 结尾优先邀请经验交流：“你现在最想把哪一步交给 AI？”比泛泛的“欢迎评论”更有效。
