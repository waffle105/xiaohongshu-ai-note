# 多图轮播视觉锁定规范

## 每日AI进化笔记的画幅分工

系列成品固定采用两种画幅，不能混用：

- 封面：9:16（推荐 1080×1920），独立入口版式，负责系列识别、标题、冲突与点击理由。
- 正文：4:5（推荐 1080×1350），小红书笔记版式，负责连续阅读、解释和收藏信息。

封面和正文共享色彩、纸张、字体家族与装饰语言即可；封面不得复制正文网格，正文不得沿用封面的大段标题布局。

用于解决多张图之间字体、字号、颜色和风格漂移的问题。生成前先写 style lock，生成时把它作为每一张图提示词的固定前缀；不要每页重新发挥。

## 默认 style lock：warm editorial handnote v1

除非用户指定其他风格，使用以下固定参数：

```text
画布：1080×1350，4:5，安全边距 72–88 px
背景：暖白纸张 #F6F3EE，轻微纸张纹理和细网格
文字：深墨 #17191C；强调色为低饱和钴蓝 #3E63DD；荧光黄绿只做 5% 以内标记
字体：全组统一使用同一中文无衬线字体，优先思源黑体 / Noto Sans CJK SC；标题 SemiBold，正文 Regular/Medium
字号：标题 52–64 px，正文 34–42 px，小标签 24–28 px；标题与正文比例控制在 1.35–1.6 倍
行距：标题 1.08–1.18，正文 1.45–1.6；标题最多两行，正文按短段落排版
版式：标题区、解释区、要点区、视觉区固定为同一套网格；页码统一放右上或左下，不来回移动
装饰：同一套蓝色手绘下划线、箭头、胶带或批注符号；每页最多 2–4 个，保持克制
```

标题和正文使用同一字体家族，不要使用“标题黑体 + 正文宋体 + 手写体”三套字体混搭。即使想制造层级，也优先用字重、颜色、下划线和卡片背景，不靠巨大的标题或装饰字体。

## 多图生成协议

1. **先锁定**：在生成第 1 张前，确定 style lock、手绘程度和页面网格。
2. **再复用**：每张提示词都复制同一段 style lock，固定画幅、模型、色彩、字体描述和负面约束。
3. **保持参考**：图像工具支持参考图时，让后续页面参考封面或风格锚点；只改变页面的信息任务，不改变纸张、字体、色彩和装饰语言。
4. **文字后排**：如果需要精确中文，先生成一致的底图和视觉元素，再用同一字体后期排版；不要让每张图像模型自由选择中文字体。
5. **统一复核**：把整组图放在一起检查，重点看标题字体、标题大小、正文密度、边距、背景纹理和手绘笔触。任何一张明显像另一套模板，都要重做。

## 面向女性用户占比较高场景的审美取向

这里的“女性用户偏好”指内容消费场景的常见审美倾向，不代表所有女性用户。优先考虑：

- **温暖而不甜腻**：暖白、米色、浅灰、雾蓝、鼠尾草绿、低饱和珊瑚色，比纯黑霓虹更容易建立亲近感。
- **知性而不冷硬**：保留清晰网格和信息结构，同时加入纸张、桌面、批注、手账、文件夹等真实工作物件。
- **细腻而不空洞**：使用有触感的纹理、细线、轻微不规则标记，但必须给文字留出足够空间。
- **有生活感**：适当使用咖啡桌、办公桌、便签、笔记本、手部操作等场景；不要凭空加入人物、化妆品或女性符号。
- **可保存和可分享**：页面看起来像一页精致的知识手账或杂志摘录，读者能截图保存，也能转发给同事或朋友。

避免把这种方向做成粉色模板、爱心贴纸、少女漫画或过度装饰。审美的目标是“让人愿意靠近并读下去”，不是削弱 AI 观点的专业度。

## 手绘风自动判断

### 选择“编辑排版 + 手绘批注”混合风（默认推荐）

适合：AI 工作感悟、个人观察、职业思考、轻教程、经验分享、方法清单、需要增加亲近感的内容。

做法：保持正文和标题为统一无衬线字体，只加入少量手绘下划线、圈选、箭头、胶带、批注或手写编号；手绘元素占画面视觉面积不超过 15%，不要让它覆盖正文。

### 选择纯编辑风

适合：行业趋势、技术定义、产品对比、数据解读、企业治理、成本与风险、需要显得可靠和克制的内容。

做法：使用规整网格、卡片、流程和少量几何隐喻；不使用明显涂鸦或不规则手写标题。

### 选择更明显的手绘风

适合：个人故事、失败复盘、情绪表达、生活化经验、轻松的创作者口吻，且内容本身不依赖大量精确数据。

做法：可以增加手账纸、胶带、手写旁注和不规则框线，但标题仍使用统一的印刷字体，正文仍要保持可读；不要让整套图每页都变成不同画风。

### 不要使用手绘风的情况

- 需要严格展示数据、表格、技术流程或验收标准；
- 内容涉及治理、合规、风险、财务或严肃决策；
- 手绘元素会遮挡 60–120 字的核心解释；
- 用户明确要求专业、极简、商务或科技感。

## 视觉 QA 清单

- 五张图是否像同一个账号、同一篇笔记，而不是五个不同模板？
- 标题是否始终使用同一字体家族、字重和字形气质？
- 标题是否约为正文 1.35–1.6 倍，而不是突然放大两到三倍？
- 每页的安全边距、标题位置、页码位置和正文基线是否稳定？
- 颜色是否控制在暖白 + 深墨 + 1 个主强调色 + 少量标记色？
- 手绘元素是否统一笔触、统一数量和统一功能？
- 女性用户导向是否体现为温暖、细腻、生活感和易读性，而不是刻板的粉色装饰？
